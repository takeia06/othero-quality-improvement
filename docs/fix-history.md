# 修正履歴

## 001. 手番管理の不整合

- 発見日: 2026-04-03
- 関連コミット: fix: correct turn switching and pass handling

### 症状
- 先攻/後攻の扱いが分かりにくい
- パス時の手番遷移が不正になる可能性がある

### 原因
- `changeColor=(turn==true)? WHITE:BLACK;` が入力前の `turn` に依存していた
- 手番の真偽値と石色の概念が混在していた

### 修正内容
- `changeColor` を削除
- `turn` を「人間の番かどうか」に統一
- `humanIsBlack` を追加
- パス時は `turn = !turn` に変更
- `passCount` を導入

### 確認方法
- 先攻を選んで人間から始まることを確認
- 後攻を選んでCPUから始まることを確認
- 合法手なしでパスすることを確認

### 修正後結果
- 先攻/後攻で進行が破綻しない
- パス時の遷移が正しくなった
